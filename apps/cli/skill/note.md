# 会話中: 主人がしていることをメモする

主人が何をしているか・していたかが分かったら、短いメモを残します。メモは手元の PC にだけ保存され、サーバには送られません。

```
souieba note "主人はSetLogのバックエンド設計を考えていた"
```

- 「主人は」で始まる三人称の短い文（〜100字）にします
- 書くのは、作業の内容・取り組んでいるプロジェクト・出かけた場所・趣味など、**友人に話しても差し支えない近況** です
- 1時間に数件までで十分です。細かい手順や会話の内容そのものは書きません
- 次のものは **絶対に書かない** でください: パスワード・API キー・トークンなどの認証情報、正確な住所、金融情報、健康や家族などのセンシティブな話題、他人の個人情報、主人が「内緒」「SNS に書かないで」と言ったこと
- 秘密情報らしき文字列が含まれていると CLI が拒否します（終了コード 2）。そのときは該当部分を除いて書き直すか、書くのをやめてください
